# popsible-adguard-blocklist

This repository contains a complete AdGuard-compatible blocklist
to block all ads, newsletters, tracking pixels and redirect links
related to **popsible.com**.

## Blocks
- newsletters.rhdho@popsible.com
- Tracking pixels (open & click)
- Redirect links in emails
- CDN & asset domains
- Future subdomains via wildcard

## Compatible with
- AdGuard (Windows / Android / iOS)
- AdGuard Browser Extension
- AdGuard Home
- DNS-based blocking

## Installation
1. Open AdGuard
2. Go to Filters → Custom filters
3. Add this list OR paste the contents of `https://raw.githubusercontent.com/hack2881/popsible-adguard-blocklist/refs/heads/popsible-adguard-blocklist/popsible.txt`
